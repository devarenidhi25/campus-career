Empowering College Careers

CampusCareer brings student-focused internships, jobs, hackathons, and career guidance together in one modern, colorful platform.

💔

The Problem

College students waste countless hours jumping between fragmented job portals, cluttered WhatsApp groups, outdated college noticeboards, and obscure hackathon sites. Finding legitimate student internships with transparent stipends and clear eligibility criteria has historically been exhausting.

✨

The CampusCareer Solution

CampusCareer unifies student opportunities under one vibrant umbrella. Students can instantly filter roles by work mode, stipend, or skill tags, bookmark roles locally, track application pipeline stages, optimize their resumes with ATS scoring, and explore guided skill roadmaps.

Deployment Pipeline Breakdown

  • Frontend Application: Pure static website constructed using HTML5, CSS3, and Vanilla JS (ES6+). Zero heavy frameworks or backend dependencies.
  • Terraform Provisioning: Provisions an AWS EC2 instance (`t3.micro`), Security Groups allowing HTTP (Port 80) & SSH (Port 22), VPC, and Internet Gateway.
  • Ansible Automation: Executes automated playbooks to update system packages, install Docker Engine, and pull/run the Nginx container automatically.
  • Docker & Nginx Containerization: The provided Dockerfile packs the HTML/CSS/JS source into an nginx:alpine container, serving the website with low latency and minimal resource overhead.
